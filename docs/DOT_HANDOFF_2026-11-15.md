# Dot 전달용 — 대광교회 앱 출시 준비

2026-11-16 후속으로 테스트 프로젝트 생성과 실제 Auth/DB 검증을 완료했다. 최신 전달문은 [실제 Supabase 검증 기록](release-test-2026-11-16.md)의 Dot 전달문을 사용한다. 아래는 11월 15일 기준 기록이다.

2026-11-15. 기준 커밋 `53b8a610c157f7c73cbc9524a3de3ad3500e58a3` 위 로컬 미커밋 수정본. 아래 검증은 운영 서비스나 스토어 출시 완료를 뜻하지 않는다.

## 그대로 전달할 내용

Codex에서 계정 없이 가능한 로컬 수정과 검증을 진행했습니다. URL 파서 취약 의존성을 0.5.1로 수정하고 깨끗한 의존성 재설치 및 호환 패치를 확인했습니다. 스토어 앱의 APK 다운로드 안내를 차단했고, 약관·개인정보·탈퇴 준비가 없는 환경에서는 가입이 열리지 않도록 보완했습니다.

기본 95개, 출시 30개, 격리 PostgreSQL 통합 51개, 계정 흐름·목회 연결 삭제·URL 파서 4개 테스트가 통과했습니다. Android/iOS 번들 생성과 모바일 타입·lint 검사도 통과했습니다. 가상 브라우저에서는 가입→로그인→탈퇴를 확인했고, 비밀번호 복구와 기존 세션 거부는 가상 HTTP 테스트로 확인했습니다. 실제 Supabase 인증·메일·계정 삭제나 서명된 AAB/IPA·실기기 검증은 아직 수행하지 않았습니다.

목회시스템의 앱 계정 연결·상담 인계·파생 일정 삭제를 위한 SQL 009를 준비하고 격리 검증했습니다. 독립적으로 작성한 교적과 수기 기록은 자동 삭제하지 않습니다. 수동 복사본 및 실제 백업 복원 후 재삭제 범위는 추가 확인이 필요합니다. 운영 DB에는 적용하지 않았습니다.

별도 테스트 Supabase 프로젝트가 없어 실제 인증 검증은 대기 중입니다. 테스트 환경 구성안과 운영/테스트 URL 혼용을 거부하는 로컬 사전 검사를 준비했습니다. 현재 브라우저 제어로 Supabase 콘솔에 접근할 수 없어 계정의 무료 슬롯과 요금제는 미확인입니다. 새 프로젝트 생성·결제·SMTP 변경·실제 메일 발송은 하지 않았습니다.

다음 우선순위는 별도 무료 테스트 프로젝트의 사용 가능 여부 확인 → 구체적인 생성·설정 범위 승인 → 가상 회원으로 실제 가입·복구·탈퇴·삭제 worker·잔여 토큰 접근 검증입니다. 운영에서는 가입이 열려 있지만 복구·탈퇴가 꺼진 것으로 확인했으므로, 수정본만 단독 배포하면 가입이 닫힐 수 있습니다. 검증된 복구·탈퇴 설정과 함께 운영 반영 범위를 승인한 후 배포해야 합니다.

전체 모노레포 의존성 감사에는 다른 항목 19개(높음 5, 보통 14)가 남습니다. 보안 검토 전체 완료가 아닙니다. Git push·운영 배포·테스트 배포·스토어 제출·공개 출시는 하지 않았습니다.

상은님 결정 중 남은 것은 교회 조직 명의 등록 증빙·권한과 실제 수신 가능한 지원 이메일입니다. 개인정보 기준은 이미 확정되어 재결정할 필요가 없습니다: 만 14세 미만 가입 불가, 담당자 한상은 성도, 연락처 교회 대표번호, 탈퇴 시 개인 자료 삭제, 상담·심방 일반 보관 상한 5년.
