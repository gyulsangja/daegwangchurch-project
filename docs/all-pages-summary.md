# 전체 페이지 샘플 구현 기록

## 공개 홈페이지

명세에 정의된 공개 URL을 모두 구현했다.

- 홈
- 교회소개 5개 화면
- 예배 6개 목록과 영상 상세
- 교회소식 4개 목록과 각 상세
- 교회학교·사역 4개 화면
- 새가족 4개 화면
- 다시 오실 길과 개인정보처리방침

예배, 공지, 주보, 일정, 앨범 데이터는 `src/content/mock-data.ts`의 샘플을 사용한다. 실제 CMS 연결 시 페이지 컴포넌트는 유지하고 조회 데이터만 교체한다.

## 관리자 CMS

명세의 관리자 URL을 모두 접근 가능한 구조로 구현했다.

- 대시보드
- 예배, 공지, 주보, 일정, 앨범
- 고정 페이지, 사람, 사역
- 문의, 관리자, 사이트 설정
- 공통 목록, 등록, 수정 화면

현재 관리자 화면의 저장 버튼과 업로드는 UI 골격이다. Supabase 연결과 migration 후 Server Action, Zod 검증, Storage 업로드를 연결한다.

## 샘플 콘텐츠 원칙

- 실제 교회 정보로 오해할 수 있는 주소, 연락처, 설교자, 예배 시간은 준비 중으로 표시한다.
- 샘플 게시물에는 샘플임을 명시한다.
- 실제 이미지와 YouTube URL은 교회 자료 확보 후 교체한다.
