# 대광교회 재정보고의 작성 기준과 검토 범위

2026년 11월 27일 기준. 제직회·공동의회와 예결산위원회에 제출하는 내부 관리회계 자료에 적용한다.

## 회의를 준비할 때

1. 수입·지출 장부에서 각 계좌를 선택하고 동일한 종료일의 통장 잔액과 장부 잔액을 대조한다. 현금은 실제 시재와 대조한다. 차이가 있으면 이체, 누락, 중복, 취소를 먼저 확인한다.
2. 예산·결산에서 회계연도와 기간을 선택한다. 세입은 연간 목표 대비 수납액, 세출은 연간 편성액 대비 집행액을 검토한다. 월 조회의 비율도 연간 예산을 분모로 쓴다. 부서별 월 예산이 별도로 편성됐다고 해석하지 않는다.
3. 계정과목별 예산 차이, 예산 미편성 집행, 전년 동기 증감, 당기 수지 및 기말 자금을 대조한다. 발생 사유와 추경 근거를 정리한다. 예산을 바꿀 때는 해당 항목에서 변경 금액과 사유를 기록한다.
4. 위원회 자료에서 당해 연간 결산안과 차년도 예산안을 함께 검토한다. 본문에는 세입·세출 총액, 차액과 주요 안건을 싣고, 별첨에는 계정과목별 금액을 싣는다. 차년도 장부 미개설과 실제 편성액 0원을 구별한다. 기부자 이름과 개인 지급 명세는 회의에 배포하는 재정 요약에 포함하지 않는다.
5. 보존 기능을 사용하는 경우 재정 책임자가 회의록 근거와 함께 당시 자료를 보존한다. 이후 장부가 바뀌면 별도 버전을 만든다. 위원회 심의, 공동의회 의결, 외부 감사는 서로 다른 절차이며 회의록 원본·증빙·감사 의견은 해당 절차에서 보관한다.

## 현재 장부로 작성 가능한 자료

| 자료 | 근거 |
| --- | --- |
| 세입·세출 예산안과 결산안 | 연도별 편성액, 장부 반영 거래, 비활성 계정과목을 포함한 집계 |
| 기간 수지·계좌별 기말 잔액 | 현금·예금 기초잔액과 기간 입출금. 내부 이체는 전체 수지에서 제외 |
| 현금거래 분개장 | 수입·지출·계좌이체에 대응하는 차변·대변. 미결제 거래 및 비현금 결산분개는 포함하지 않음 |
| 예결산위원회 자료 | 두 연도의 예산·실적 요약과 계정과목별 부속 명세 |

## 공익법인 수준으로 확장하기 위한 선행 자료

- **재무상태표와 발생주의 운영성과표**에는 현금 외의 채권·채무, 유형자산·감가상각, 순자산 및 결산분개가 필요하다. 전환 기준일과 검증된 기초잔액을 확정한 후 보조원장과 대차 검증을 설계한다.
- **목적별 기금**은 지정헌금의 기초잔액, 사용 제한, 사용액, 기말잔액과 해제 근거가 필요하다. 헌금 종류의 이름만으로 사용 제한을 추정하지 않는다.
- **기능별 비용 보고**에는 사업수행·일반관리·모금 구분과 공통비 배부 기준이 필요하다. 인건비·시설비 등 성격별 계정만 보고 기능을 임의 지정하지 않는다.
- **감사 및 대외 제출**에 앞서 교회의 법적 지위, 적용 회계기준, 내부 의결 절차와 감사 범위를 확인한다. 현재 계좌 잔액 대조는 비교 도구이며, 독립 검토자의 대사 승인 기록이나 외부감사 의견을 대신하지 않는다.
