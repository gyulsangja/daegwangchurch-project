# 기존 Figma 기준 앱 구현 계획

기준일: 2026-10-03. `03 · App UI · Daegwang Teal`에는 88개 화면·상태 뷰가 이미 있다. 다음 단계는 이 기존 설계를 기준으로 코드에 없는 화면과 기능을 구현하는 것이다. 앞서 초기 보관 페이지만 확인하고 작성한 35개 화면 재기획안과 새 Low-Fi 제작 순서는 철회한다. 당시 제안한 화면 ID는 사용하지 않는다.

2026-10-04 업데이트: 화면별 현재 구현/체험/부분/대기는 [88개 점검표](mobile-screen-audit.md)를 우선한다. 신규 가입·계정·상담/심방·알림은 화면 및 메모리 테스트 API로 연결했고 실제 정책·운영 연결은 [회사 PC 점검표](company-pc-checklist.md)에 분리했다.

## 기존 설계를 우선하는 기준

- 홈은 오늘의 바로가기, 말씀은 콘텐츠와 묵상 시작, 소식은 공지·주보·행사·일정·공동기도, 교회는 안내·상담·심방 신청, MY는 개인 기록과 신청내역이다.
- 개인 기도는 내용 중심이며 제목 선택, 응답 상태 없음이다. 특별기도만 선택적으로 응답·감사를 관리하고 공동기도는 별도 공개 콘텐츠다.
- 교회 공식 일정, 저장한 교회 일정, 개인 일정을 구분한다. 같은 공식 일정은 통합 캘린더에서 중복 표시하지 않는다.
- 비회원의 개인 행동은 회원 기능 안내와 로그인 후 원래 콘텐츠·행동으로 복귀한다.
- 성경 위치만 표시하며 성경 전문·구절 저장은 제외한다. 시청 여부와 묵상 기록 여부는 독립적이다.
- 개인 묵상·기도는 본인만 열람하며 관리자 임의 조회 기능을 만들지 않는다. 중보기도 요청·묵상 공유는 계속 보류한다.

이는 Figma 02 페이지에 존재하는 설계 내용이다. 새 정책을 임의로 추가하거나 다시 같은 기획을 만들지 않는다. Figma에 미확정이라고 적힌 항목은 확정 정책으로 간주하지 않는다.

| 상담·심방 | 요청·확인·내역·상세 존재 | 별도 요청 도메인·권한·앱 기능 미구현 |

Figma 명세는 주요 이동을 회원 기준 프로토타입으로 연결했다고 설명한다. 입력·저장·신청은 예시 화면 전환이며 실제 기능은 없고, 비회원 인증 복귀·실데이터·오류 검증은 개발 단계라고 명시한다.

## 다음 구현 순서

2026-10-04 진행: 아래 1~4와 5의 기존 계정 로그인·개인 기록, 6의 개인 일정/교회 일정 저장을 구현했다. 실제 DB/Supabase 통합 검증과 운영 정책 확정은 남아 있다. 회원가입/복구/탈퇴, 알림, 상담·심방은 준비 안내 상태다. 최신 세부 상태와 다음 단계는 HANDOFF 마지막 절을 우선한다.

1. 기존 Figma의 홈 H01(8:5), 말씀 W01(8:295), 목록 W02(8:332), 상세 W03(8:353), MY 비회원 M05(10:326)를 디자인 컨텍스트와 스크린샷으로 확인한다. 04 테마와 실제 코드 토큰을 비교한다.
2. 기존 화면에 맞춰 공통 UI와 5개 메뉴의 내비게이션을 연결한다. 기능이 없는 화면을 동작하는 것처럼 표시하지 않는다. 샘플 미리보기와 실제 API 실행을 구분한다.
3. 홈·말씀 화면을 구현하고 현재 목록·상세를 연결한다. 새 홈 경로와 기존 상세의 뒤로가기·오류 복귀 경로를 함께 정리한다.
4. 소식·교회 공개 화면을 기존 디자인 순서대로 구현하고 필요한 공개 DTO/API를 추가한다. 이미 있는 홈페이지·CMS 데이터를 재사용한다.
5. 인증 방식과 개인 데이터 정책을 정한 뒤 회원·묵상·기도 기능을 구현한다. 개인별 소유권, 관리자 접근 차단, 저장 실패와 로그인 복귀를 검증한다.
6. 일정·알림·상담·심방·계정 관리 기능을 기존 설계와 운영 정책에 맞춰 순차 구현한다.

각 단계에서 필요한 화면만 확인한다. 화면·디자인 시스템·와이어프레임을 처음부터 다시 만들지 않는다. 운영 DB 변경과 배포는 별도 요청 범위다.

## Figma가 명시한 미확정 항목

인증 방식과 필수 수집 항목·실제 약관, 시청 완료 기준, 동일 말씀의 여러 묵상 허용, 임시저장·오프라인·기기 간 충돌, 비회원 기록과 알림센터, 콘텐츠 삭제 후 본문 보존, 응답 상태 되돌리기, 종일 일정과 시간대·발행 전 알림, 탈퇴·보관기간이다. 화면이 있다는 사실과 해당 정책이 확정됐다는 사실은 구분한다.
