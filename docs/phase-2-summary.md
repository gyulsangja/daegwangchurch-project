# Phase 2 완료 기록

## 구현 범위

- 공개 서브페이지 공통 Hero, 콘텐츠 컨테이너, 하위 메뉴
- 교회소개, 비전과 사명, 섬기는 사람들, 교회연혁, 예배안내
- 새가족 안내, 새가족 등록 안내, 새가족 교육, 문의 안내
- 다시 오실 길, 개인정보처리방침 준비 화면
- 페이지별 Metadata와 sitemap 경로

## 확정 자료 대기 항목

- 교회 최종 도로명 주소와 지도 좌표
- 주일·주중 예배의 정확한 시간과 장소
- 대표 전화번호와 이메일
- 담임목사 인사말, 약력, 프로필 사진
- 교역자와 사역자 정보
- 교회·예배·사역 실제 사진
- 정식 개인정보처리방침

확인되지 않은 항목은 임의의 값으로 채우지 않았으며, 운영 자료가 준비되면 CMS 데이터로 연결한다.

## 품질 검사

- `npm run lint` 통과
- `npm run type-check` 통과
- `npm run build` 통과
- 18개 애플리케이션 라우트 생성 확인
