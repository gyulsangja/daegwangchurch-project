작성 기준일: 2026년 10월 18일. 운영 책임자가 확정할 항목을 `[확정 필요]`로 표시한 검토본이다. 현재 공개 중인 온라인 문의 방침을 대체하는 최종본이나 스토어 제출 완료 문서가 아니다. 아래 정책을 확정할 때 앱의 실제 동의 화면·삭제 작업·백업 설정과 함께 맞춘다.

## 개인정보처리방침 본문 초안

대한예수교장로회 대광교회(이하 ‘교회’)는 공식 홈페이지와 대광교회 앱을 운영하며, 서비스 제공에 필요한 개인정보를 아래와 같이 처리합니다. 공개된 말씀·주보·교회 안내는 회원가입 없이 이용할 수 있습니다. 개인 기록과 교인 확인 등은 회원가입 또는 해당 기능의 별도 신청이 필요합니다.

### 처리 목적과 항목

| 이용 기능 | 처리 항목 | 목적과 선택 여부 |
| --- | --- | --- |
| 이메일 회원가입·로그인 | 이메일, 인증 정보, 회원 식별자, 계정 생성·인증 시각 | 회원 인증, 계정 관리, 비밀번호 복구. 회원 서비스 이용에 필요 |
| 소셜 로그인 | 실제 활성화한 제공자의 사용자 식별자와 동의한 프로필·이메일 | 이용자가 선택한 로그인 처리. 제공자와 수집 항목은 실제 설정에 맞춰 고지 |
| 회원 프로필 | 표시 이름, 정책 동의 버전·시각 | 이름 표시 및 동의 이력 관리 |
| 교인 확인·소속 | 본인이 제출한 이름·연락처·직분, 확인 요청·승인 상태, 소속 | 선택 신청에 따른 교인 확인과 소속 소식 제공. 일반 가입과 구분 |
| 묵상·기도·개인 일정 | 작성 본문, 날짜, 연결한 말씀, 기도 상태·응답 기록, 일정 제목·메모·장소 | 이용자가 작성한 개인 신앙 기록 저장과 조회. 작성하지 않아도 공개 콘텐츠 이용 가능 |
| 저장한 말씀·관심 모임 | 저장 대상과 시각, 관심 모임·선택 설정 | 개인 목록과 소식 제공 |
| 상담·심방 | 요청 종류, 이름·연락처, 원하는 연락 방법·일시, 요청 내용과 처리 상태 | 별도 신청한 돌봄 요청을 지정 담당자에게 전달 |
| 알림 | 선택한 알림 항목·시간, 기기 플랫폼, 설치 식별자, 푸시 토큰, 발송 상태 | 동의한 기기에서 선택한 소식 전달. 알림을 거절해도 다른 기능 이용 가능 |
| 홈페이지 문의·삭제 요청 | 이름, 전화번호 또는 이메일, 연락 방법, 제목·요청 내용, 동의 시각 | 문의 답변, 계정 소유 여부 확인, 삭제 요청 처리 및 결과 안내 |
| 보안·운영 | 요청 제한용 식별값, 오류 및 접근 기록 등 실제 서비스가 생성하는 정보 | 부정 사용 방지와 장애 대응. 구체 항목·보관 기간은 호스팅·인증 로그 설정 확인 후 확정 |

비밀번호를 기기에 저장하지 않으며 인증 서비스에서 처리합니다. 로그인 유지를 위해 기기에 세션 토큰을 저장합니다. Android는 Keystore 기반 보안 저장소, iOS는 Keychain을 이용합니다. 사용자는 로그아웃할 수 있습니다. 기도·상담·문의에는 다른 사람의 정보나 서비스에 필요하지 않은 주민등록번호·신분증·비밀번호·인증번호를 입력하지 마세요.

### 민감정보와 아동 정보

교인 여부·소속·직분과 종교적 신념, 기도·상담에 포함된 건강 정보 등은 민감정보에 해당할 수 있습니다. `[확정 필요: 해당 처리의 법적 근거, 별도 동의 항목·보관 기간, 동의 철회 방법]`. 선택 정보에 동의하지 않더라도 공개 말씀과 교회 안내는 이용할 수 있습니다.

`[확정 필요: 만 14세 미만 서비스 정책]`. 현재 코드에 법정대리인 확인 절차가 갖춰졌다고 안내하지 않습니다. 만 14세 미만 가입을 허용할 경우 동의 절차와 수집 항목을 구현한 후 최종 방침에 반영합니다.

### 개인 기록과 담당자의 접근

개인 묵상·기도는 일반 회원·소속 구성원에게 공개되지 않으며 일반 관리자 화면에서 조회하는 기능을 제공하지 않습니다. 상담·심방은 개인 기록과 별도로 지정된 담당자에게 전달됩니다. 교인 확인 자료는 승인 업무를 수행하는 관리자에게 제공됩니다.

이 설명은 종단간 암호화를 의미하지 않습니다. 서버·데이터베이스 운영 권한을 가진 사람의 접근 가능성을 고려하여 업무상 필요한 범위로 권한을 제한하고 기록을 관리해야 합니다. 실제 운영자 권한·감사 방식은 공개 전 확인합니다.

전자 파일은 복구가 어렵도록 삭제하며, 출력물이 있다면 분쇄 등으로 폐기합니다. 법령에 따라 보존할 자료가 있다면 구체적인 법령·항목·기간을 최종 방침에 기재하고 다른 자료와 분리합니다. ‘법령상 필요 시 보관’만으로 모든 자료를 무기한 보관하지 않습니다.

### 계정 삭제와 이용자 권리

앱의 MY → 계정관리 → 회원탈퇴에서 요청할 수 있습니다. 앱을 이용할 수 없는 경우 홈페이지의 `/account-deletion`에서 로그인 없이 요청할 수 있습니다. 웹 요청은 관리자 문의함에 접수되며, 계정 소유 여부를 확인한 후 처리합니다. 비밀번호나 인증번호를 문의 양식으로 받지 않습니다.

삭제 대상은 계정과 연결된 프로필, 묵상·기도, 저장 목록, 일정, 알림, 기기 푸시 정보, 교인 확인·소속 및 상담·심방 요청입니다. 공용 설교·주보, 별도 홈페이지 문의와 관리자 감사 기록은 계정 기록과 구분합니다. 남는 자료의 목적·기간을 최종 방침에 명시합니다. 접수와 계정 삭제 완료는 구분하여 안내합니다.

이용자는 개인정보 열람·정정·삭제·처리정지 및 동의 철회를 요청할 수 있습니다. `[확정 필요: 담당자 및 연락처, 대리인 확인 방법, 처리 절차와 법정 기한 준수 운영]`.

### 처리 위탁과 국외 이전

다음은 코드에서 확인되는 서비스 관계이며, 계약상 법인·처리 국가·보관 조건의 확정 표가 아닙니다. 실제 계약과 대시보드 설정을 확인한 뒤 위탁과 제3자 제공, 국외 이전을 각각 구분하여 공개합니다.

### 권한과 저장 기술

푸시 알림 권한은 선택입니다. 사용자는 앱 및 운영체제 설정에서 해제할 수 있습니다. 현재 교회 위치 지도는 고정 주소를 표시하며 사용자의 현재 위치를 수집하기 위한 기능은 아닙니다. 사진·연락처·마이크 등의 권한이 추가될 때는 해당 기능과 수집 목적을 다시 안내합니다.

앱은 로그인 상태를 위한 보안 저장소를 사용하고 웹 미리보기는 브라우저 저장소를 사용할 수 있습니다. 영상·지도 등 외부 서비스를 열면 해당 서비스의 쿠키와 정책이 적용될 수 있습니다. 광고·분석 SDK의 실제 사용 여부는 스토어 데이터 신고와 함께 점검합니다.

## 동의 화면과 스토어 신고의 동시 보완

- 가입 필수 처리, 선택 알림, 교인 확인 민감정보, 상담 전달을 하나의 체크박스로 묶지 않는다. 별도 고지와 필요한 동의 기록을 설계한다.
- 앱의 가입·개인정보 화면이 서버 policy 본문을 사용하므로 웹 문서만 바꾸고 완료로 처리하지 않는다. 동일한 최종 문구와 버전을 운영 API에 반영하고 실제 표시를 검증한다.
- Google Data safety와 Apple App Privacy에는 이메일·이름·전화·사용자 ID·종교 관련 정보·사용자 콘텐츠·푸시 식별자 및 SDK 처리를 실제 범위로 분류한다. 처리 위탁이 곧바로 모든 ‘공유’ 신고를 뜻하는지 여부는 각 스토어 정의에 따라 확인한다.
- 스토어에 ‘데이터 수집 없음’, ‘완전 익명’, ‘종단간 암호화’로 신고하지 않는다. 암호화 전송과 서버 저장 데이터 접근 권한은 다른 개념이다.
