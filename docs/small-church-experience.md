# 작은 교회의 말씀·묵상·기도 경험

## 기준과 검토

사용자가 알려준 대광교회의 상황: 약 40명, 어른 약 20명과 청소년·청년으로 구성되며 앱 이용은 청년 중심으로 예상된다. 실제 사용자를 조사한 결과가 아니라 이 설명과 기존 기획/구현을 토대로 한 설계다.

기존 기획은 말씀 → 묵상 → 기록 → 기도 → 교회생활이다. 저장소의 PROJECT_CONTEXT, mobile-screen-audit에 정리된 H01/H04(홈), D 계열 말씀 상세, R 계열 묵상, P 계열 기도 및 실제 홈·말씀·소식·교회·MY·작성/조회·도움말 경로를 검토했다. Figma 원본을 이번 작업에서 다시 조회하거나 수정한 것은 아니다.

문제는 홈의 여러 메뉴가 첫 행동을 가리고, 말씀 다음에 바로 글쓰기를 요구하는 듯한 흐름이었다. 적은 인원에게 게시판 활성화·매일 작성·참여 경쟁을 요구하지 않고, 한 사람만 써도 도움이 되는 개인 신앙생활을 우선한다.

## 반영한 흐름

- 홈: 최근 말씀을 먼저 열기 → 로그인 없는 잠시 기도하기 / 나의 기록 → 주보·소식 → 도움말. 상담·일정·모임은 기존 교회/소식/MY에서 계속 이용한다.
- 말씀 상세: 영상과 성경 위치 → 마음에 남는 한 가지 → 하나님께 맡기기 → 작은 실천. 기록은 선택이다. 기존 ‘묵상 기록하기’ 바로가기도 유지한다.
- `/quiet-prayer`: 로그인·서버 요청 없이 화면 안에서 마음 모으기/기도/일상 안내를 읽는다. 이미 열린 화면은 네트워크가 끊겨도 사용할 수 있다. 앱 전체 오프라인 기능은 아니다.
- 큰 글씨 전환, 최소 48px 수준의 조작 영역, 세로 스크롤과 줄바꿈을 적용했다. 시스템 글자 확대도 기존대로 유지한다. 네이티브 화면 읽기 기능과 시스템 최대 글자 크기는 실기기 검증이 남는다.
- 작성: 한 문장도 허용하고 감사/걱정/생각나는 사람처럼 시작할 단서를 제공한다. 본문을 제목·날짜보다 먼저 배치한다. 남의 기도나 AI 기도문으로 사용자의 기록을 자동 채우지 않는다.
- 읽기·기도 안내의 다음 버튼은 신앙 활동 완료 기록을 만들지 않는다. 점수·연속 출석·순위·남의 작성 수를 추가하지 않았다.
- 저장만 기존 회원 인증을 사용한다. 개인 묵상/기도를 관리자가 보거나 공동체에 공유하는 기능은 추가하지 않았다.
- MY의 미구현 ‘시청 기록’ 메뉴를 제거했다. 실제 동작하는 ‘저장한 말씀’은 유지한다.
- 화면에서 영어 MY 대신 ‘나의’ 탭과 ‘나의 기록’ 제목을 사용한다. 기존 `/my` 경로는 유지한다.

## 홈페이지 디자인 보강

기존 주제별 구성은 유지하고, 묵상 면의 책갈피, 주보의 책등과 종이 음영, 작은 제목 구분선, 환영 안내의 얕은 그림자를 추가했다. 영상 확대 효과는 동작 줄이기 설정을 따르며 새 이미지/글꼴/운영 콘텐츠를 만들지 않았다.

## 운영 제안과 다음 확인

새 글을 매일 따로 제작하는 부담을 만들지 않는다. 기존 주일 말씀·첫시간·주보를 한 번 등록하는 통합 관리 정책을 유지한다. 첫시간이 매일 올라오지 않으면 실제 날짜와 ‘최근 묵상’으로 표시한다.

청년과 어르신 각 2명 정도에게 다음 네 가지를 함께 확인하는 것을 제안한다: 도움 없이 말씀 열기, 큰 글씨로 기도 안내 읽기, 한 문장 저장 후 다시 찾기, 기록이 비공개임을 이해하기. 설치 수보다 ‘혼자서 다음에 다시 사용할 수 있는지’를 본다. 이 사용성 확인은 아직 실행하지 않았다.

## 검증과 제한

`scripts/verify-faith-practice.mjs`는 비회원 홈 → 기도 안내 → 큰 글씨 → 네트워크 차단 중 단계 이동 → 선택적 기록의 로그인 진입과 서버 쓰기 0건을 검사한다. `scripts/verify-ux.mjs`는 기존 개인 묵상 저장/재로그인/기도 연결/일정 흐름의 회귀 검사다. 기존 메모리 체험 API를 사용하며 운영 Supabase·푸시·실제 교인 데이터 검증은 아니다.

구현 시 확인한 공식 문서: [Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/), [Expo Router](https://docs.expo.dev/router/introduction/).
