# 홈페이지 디자인 검토와 수정 (2026-10-04)

## 재피드백 반영 — 현재 화면

개별 콘텐츠마다 같은 높이의 영역을 반복한 구성을 폐기했다. 명료한 주제를 유지하면서 주일 말씀/매일 묵상, 주보/공지/일정, 교회 소개/새가족 방문을 각각 묶었다. 대표 인사 이미지, 큰 말씀 면과 작은 묵상 면, 종이 형태의 주보와 공지 목록, 편지처럼 구성한 환영 안내로 표현을 달리했다. 아래 ‘독립 영역’ 기록은 과거 작업이며 현재 원칙이 아니다.

실제 데이터가 없는 곳은 콘텐츠의 용도를 설명하는 안내를 보여준다. 주보 그림은 실제 주보의 복제품이 아닌 장식이다. 하위 화면은 제목/설명을 나란히 두고 정보 카드 테두리를 줄여 메인의 여백·색감과 맞췄다.

## 사용자 피드백 반영 — 최신 기준

아치·큰 식물 장식을 제거하고 제목도 프리텐다드를 사용하도록 되돌렸다. 이번 화면에는 명조 강조가 필요하지 않아 KoPub바탕을 추가하지 않았다. 향후 명조를 사용할 때는 KoPub바탕만 제한적으로 적용한다.

주일 말씀, 첫시간, 주보, 공지, 일정, 교회 소개, 새가족 안내를 각각 독립 영역으로 나눴다. 한 영역에 다른 콘텐츠 카드나 표어를 끼워 넣지 않는다. 영상이 없을 때 큰 빈 플레이어를 만들지 않는다. 홈페이지와 앱의 콘텐츠 관리 기준은 [unified-content.md](unified-content.md)를 따른다. 아래는 최초 수정의 기록이며 아치·명조 관련 내용은 현재 디자인에 적용되지 않는다.

## 검토

기존 첫 화면은 큰 고딕 제목, 영어 표제, 청록색 면적과 반복되는 카드가 중심이라 기업 소개 화면에 가까웠다. 예배·말씀·공동체라는 성격을 첫 화면에서 더 분명히 보여주고, 처음 방문하는 분이 예배 안내와 찾아오는 길을 쉽게 찾도록 수정했다. 아래 평가는 디자인 검토 결과이며 실제 교인 사용성 조사 결과는 아니다.

## 반영

- 작은 대한예수교장로회 / 큰 대광교회 표기를 유지했다. 공통 로고는 바꾸지 않았다.
- 홈페이지 전용 아이보리·차분한 녹색 팔레트와 명조 제목을 적용했다. 본문은 기존 가독성 높은 서체를 유지했다. 제목은 기기 내 명조 서체를 사용하므로 운영체제마다 모양이 조금 다를 수 있다.
- 성경·올리브 수채화 삽화를 아치 형태로 배치했다. 기존 앱 자산을 JPEG로 최적화해 홈페이지 public에 저장했다(약 190KiB). 실제 교회 사진이 아니다. 원본 생성 지시와 출처는 [groups-and-brand.md](groups-and-brand.md)에 있다.
- 첫 화면에서 예배 안내·새가족 안내 버튼과 예배 시간 영역을 찾기 쉽게 배치했다. 실제 예배 시간·영상·공지·CMS 문구와 표시 여부 설정을 유지했다.
- 교회 소개·비전·새가족 안내의 강한 색상 블록을 차분한 배경과 말씀·새싹·섬김 아이콘으로 정리했다. 공통 상단의 영어 표제를 한국어 안내로 바꿨다.
- 공지·주보·일정 목록을 제목과 날짜 중심으로 정리했다. 빈 목록에는 다음 소식이 게시되는 위치임을 안내했다.
- 현재 메뉴 표시, 모바일 메뉴의 이동 후 닫기·Escape 닫기, 키보드 본문 바로가기를 추가했다.
- 오시는 길의 개발 환경 변수 설명을 방문자용 안내로 바꾸고, 주소가 없을 때 동명 교회 검색으로 연결되지 않게 했다.

## 검증 방법

홈페이지를 실행한 상태에서 저장소 루트의 `node scripts/verify-website-design.mjs`를 실행한다. 기본 주소는 `http://localhost:3000`이며 `WEBSITE_URL`로 변경할 수 있다. 로컬 Edge가 필요하다.

- 주요 9개 경로를 1440·390·320px에서 확인: HTTP 200, 대표 제목, 가로 넘침, 브라우저 실행 오류.
- 삽화 로딩, 키보드 본문 이동, 모바일 메뉴 닫기와 현재 메뉴 표시 확인.
- PC·휴대폰 홈, 비전 페이지 스크린샷을 `apps/website/test-results`에 저장하여 직접 확인.

## 실제 연결 이후 확인할 점

- 현재 확인은 DB 미연결 상태의 기본 콘텐츠·빈 목록을 포함한다. 실제 공지의 긴 제목, 여러 예배 시간, 교회 사진, 영상 썸네일이 들어온 화면은 연결 후 다시 확인한다.
- 실제 교회·예배·공동체 사진이 준비되면 사용 허락을 확인하여 앨범과 소개 영역에 반영한다.
- 주소, 연락처, 예배 시간은 교회 확인 자료로 입력한다. 이번 수정에서 임의 값을 넣지 않았다.
- 운영 DB, 관리자 권한, 실제 문의 전송, 배포는 이번 디자인 변경 범위에 포함하지 않는다.
